שרת משחק הטריוויה

השרת הוא קובץ Node.js אחד (בלי התקנת חבילות). קבצים: server.js, questions.json, package.json.

=== העלאה ל-Railway (מומלץ) ===
1. פתח repository חדש ב-GitHub והעלה אליו את שלושת הקבצים (server.js, questions.json, package.json) בתיקייה הראשית.
2. ב-railway.app: New Project  ->  Deploy from GitHub repo  ->  בחר את ה-repository.
3. אחרי שהפריסה מסתיימת: Settings  ->  Networking  ->  Generate Domain.
   תקבל כתובת כמו  https://משהו.up.railway.app
4. פתח את הכתובת בדפדפן. אם רואים  {"ok":true,...}  השרת עובד.
5. באפליקציה: כפתור ⚙ במסך הראשי, מדביקים את הכתובת ושומרים.

=== הרצה על המחשב (לבדיקה) ===
    node server.js
השרת עולה על פורט 3000. באפליקציה (באותה רשת Wi-Fi) מכניסים  http://כתובת-ה-IP-של-המחשב:3000

=== הגדרות (משתני סביבה, לא חובה) ===
QUESTION_MS  זמן לשאלה במילישניות (ברירת מחדל 10000)
REVEAL_MS    זמן הצגת התשובה הנכונה (ברירת מחדל 2500)
START_MS     ספירה לאחור לפני השאלה הראשונה (ברירת מחדל 3000)

=== הוספת שאלות ===
בקובץ questions.json כל שאלה היא רשימה: [שאלה, תשובה נכונה, שגויה, שגויה, שגויה].
